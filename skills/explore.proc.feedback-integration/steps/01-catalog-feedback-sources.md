# Step 1: Catalog Feedback Sources

Identify the source, role, and scope of the feedback before any analysis.

```
Feedback Catalog

Source: [Stakeholder name / Role / External reviewer]
Feedback type: Edited HLD version / Written critique / Verbal notes
Sections affected: [List of HLD sections with changes]
Total distinct changes/critique points: [N]

Reviewer context (if known):
- Domain expertise: [What this reviewer knows well]
- Organizational role: [PM / Engineer / Architect / Leadership]
- Domain ownership: [If reviewer owns an adjacent domain, their boundary comments carry weight]

How would you like to proceed?
- Proceed with audit — no additional context needed
- Add context — I'll share relevant background about this reviewer
- More feedback — I have additional feedback sources to upload first
```

**STOP**: Wait for architect to provide any additional context about the feedback source.
