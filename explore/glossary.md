# GYM_SCHEDULER Glossary

Shared product and domain terminology will be recorded here during discovery.

| Term | Definition |
|------|------------|
| User | Authenticated gym member who owns schedule data. |
| Schedule | The user's single weekly training plan. |
| Schedule Card | One daily section in a schedule. |
| Exercise | A physical activity that can be planned. |
| Exercise Assignment | An exercise placed on a specific day with workout details. |
| Membership Value | Perceived usefulness or benefit provided by the gym membership. |
| JWT | Access token used to authorize API requests. |
